## 日本語<ruby>平叙文<rt>へいじょぶん</rt></ruby>
**ノートス：ー**

|       | 丁寧形                      | 普通形       |
| ----- | ------------------------ | --------- |
| 現在形   | 名詞＋です                    | 名詞＋だ      |
| 過去形   | 名詞＋でした                   | 名詞＋だった    |
| 現在否定形 | 名詞＋じゃありません・ではありません       | 名詞＋じゃない   |
| 過去否定形 | 名詞＋じゃありませんでした・ではありませんでした | 名詞＋じゃなかった |
**例：ー**
- 私は元気じゃありません・じゃない。
- 雨じゃアありません・じゃない。
- 私は大学院だ・です、木村さんも大学院だ・です。
- 去年頃学生でした・だった。
