## 動詞「たい」形 
**ノトス**
- 動詞「たい」形では、希望と願望が示せる。

|       | 活用        |
| ----- | --------- |
| 現在形   | 動詞＋たい     |
| 過去形   | 動詞＋たかった   |
| 現在否定形 | 動詞＋たくない   |
| 過去否定形 | 動詞＋たくなかった |

**例：ー**
- <ruby>歌<rt>か</rt></ruby><ruby>舞<rt>ぶ</rt></ruby><ruby>伎<rt>き</rt></ruby>を見たことがないので、一度見てみたいだ。
- ミラさんに会いたくない
- 納豆を絶対に食べたくなかった。
- 会議に間に合いたかったのに、途中で交差点で事故に遭ったから、出席できなかったです。
