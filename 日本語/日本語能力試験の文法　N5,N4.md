## 日本語助詞
###### **「<ruby>対比<rt>たいひ</rt></ruby>のは」「主題の助詞」topic marker**
**ノトス：ー**
- 旧情報→「は」。
- <ruby>主題<rt>しゅだい</rt></ruby>の「は」＋<ruby>疑問詞<rt>ぎもんし</rt></ruby>。
**会話例：ー**
- Aさん：これは何ですか。
- Bさん：これは中村先生の歴史本だろう。　
###### **「<ruby>中立叙述<rt>ちゅうりつじょじゅつ</rt></ruby>のが」neutral descriptive marker**
**ノトス：ー**
- 新情報→「が」
- 疑問詞疑問文（どれ、どんな、いつ、何、誰）＋が
**例：ー**
**新情報**
- 私が警察官です。
- スーパーの駐車場に車が沢山有ります。
- これが私のペンです。
**疑問詞**
- どれが佐藤さんの電車ですか。
- 誰が学生ですか。
- 潤子さんが教師ですか。
**会話例：ー**
- A：ルビちゃん誰が好き。　「冗談だ、笑！　：）」
- B：愛すクレムよりもあなた。
#### **「も」副助詞
**例：ー**
- 私は学生です、花子ちゃんも学生です。
- 私は日本を勉強する、港さんも日本語を勉強する。
#### **「か」疑問のマーカ 
**ノートス**
- 〜か〜か　to say or.
- 〜か　for question marking.
- 〜か〜どうか　to ask whether or not.
**例：ー**
- 今日は暑いですか 。
- 来週の会議は木曜日ですか、金曜日ですか。
- これは鉛筆ですか、プルペンですか。
- 来週僕達は動物園か映画館へ行こう。
- 誕生日はお父さんかお母さんがケーキを作ってくれます。
- 今日はケーキかラメンを作ると思う。
- 明日はまみさんも来るかどうか知っている。
#### **「の」 連体助詞**
**例：ー**
- これはミルクちゃんの鞄です。
- 麻子は自分の彼女の名前です。
- これはねんだ先生のリンゴです。
- それは本当に佐藤さんの傘です。
- あなたの奥さんの生年月日は何ですか。
- 今日の天気は悪いのでした。
- 日本の映画が面白いですね。
- スパの近くに駅があります。
- この映画の主人公はトムジェレです。
#### 「で」格助詞
**例：ー**
- 電車で駅に行き友達に合う
- 大学に車で行きます
- 娘は桜大学で数学を習っていました。
- 私はCIC大学で通信工学部から卒業しました。
#### 「から」格助詞 
**ノートス**
- 起点（始まり）と終了点（終わり）を示す→（開始時間と終了時間・開始場所と終了場所）。
- 理由を示す。
- 接続行動を示す。
- 原材料から物が作られることを示す。
- 行動の起源を示す。
**例：ー**
**理由**
	- 雨が降るから、サッカーの試合に行けない。

 **会話例：ー**
	- A：首相が入院したのを知っていますか。
	- B：えっ、どうしたんですか。
	- A：胃の病気ですから。

**接続行動**
	- 宿題を終わってから、ゲムを遊ぶ。
**開始時間と終了時間**
	- 本店は午前９時から、午前５時まで開店しています。
**開始場所と終了場所**
	- 私の家から学校まで、何時間かかりますか
**原材料**
	- ワインは葡萄から作られます。
**行動の起源**
- 授業から哲学を習ってくれた。

## <ruby>比較<rt>ひかく</rt></ruby>の「より」
**ノートス：ー**
- 名詞１＋の方が＋名詞２＋より＋形容詞。
- 名詞１＋は＋名詞２＋より＋形容詞。
**例：ー**
- 太陽は蝋燭より明るい。
- バソコンは電卓より速いでしょう。

- 野菜の方がポテチより体にいい。

## がvsは。
**(1) 肯定文**
「旧情報→（は）を使います」
「新情報→（が）を使います」
**例：ー**
- 授業にミラさんとサントスさんがいます、ミラさんは先生ではありません、サントスさんは先生です。
**(2)疑問詞疑問文**
「どれ、どこ、どちら、何、誰、いつ、どんな」＋（が）。
（は）＋「どれ、どこ、どちら、何、誰、いつ、どんな」。
**例：ー**
1. **「疑問詞のが」**
	- どれが佐藤さんの車ですか。
	- これが私の車です。
	- あの人がミラさんですか。
2. **「主題のは」**
	- この車は佐藤さんの車ですか。
	- 私の車はこれです。

## いー形容詞となー形容詞
**レッスンの導入：ー**
今は日本語の形容詞について説明します。日本語能力試験において、形容詞はとても必要です。この授業では、「い形容詞」と「な形容詞」の使い方を勉強しましょう。
**ノートス：ー**
例えば（綺麗「な」/英語翻訳 : clean、難しい「い」/英語翻訳:hard）
*普通形の活用は：ー*

|       | イー形容詞   | なー形容詞    |
| ----- | ------- | -------- |
| 現在形   | 難しい     | 綺麗だ      |
| 過去形   | 難しかった   | 綺麗だった    |
| 現在否定形 | 難しくない   | 綺麗じゃない   |
| 過去否定形 | 難しくなかった | 綺麗じゃなかった |
*丁寧形：ー*

|       | イー形容詞     | なー形容詞                |
| ----- | --------- | -------------------- |
| 現在形   | 難しいです     | 綺麗です                 |
| 過去形   | 難しかったです   | 綺麗でした                |
| 現在否定形 | 難しくないです   | 綺麗じゃありません・ではありません    |
| 過去否定形 | 難しくなかったです | 綺麗じゃありませんでした・ではありません |
	 名詞の前にな形容詞＋なを追加しなければならない。
**質問の作り方：ー**
- 〜はどんな「町、所、.....etc」ですか。
**例：ー**

## 条件形 conditional statment
###  一番「たら」形動詞

**ノートス**：ー
- 名詞＋だったら
- なー形容詞＋だったら
- いー形容詞＋~~い~~かったら
- 動詞た形＋ら
	- **<ruby>確定条件<rt>かくていじょうけん</rt></ruby>：現実的に起こることを前提とする。**
	- **<ruby>仮定条件<rt>かていじょうけん</rt></ruby>：もし〜ならという仮定の状況を示す。**

<p style="text-align:center;">確定条件vs仮定条件の作り方</p>

**例：ー**
**確定条件：ー**
- 6時になったら、夕飯を食べましょう。
- 家へ帰ったら、すぐシャワを浴びます。
- 急いだら間に合うよ。
- 春になったら、USAへ行きます。
- 30歳になったら、綺麗な彼女と結婚します。
**仮定条件：ー**
- 学生だったら、とても勉強します。
- <ruby>綾音<rt>あやね</rt></ruby>さんがエンジニアになったら、悲しくなります
- もし時間がなかったら、本を読みません。
- もし次年は住んだったら、日本語能力試験を受けます。
- 日本へ行ったらラメんを食べたり富士山に登ったり音楽を歌ったりしたいです。
- 大人になったら世界中を旅行したいです。
- 遅れたらすみません。

**「〜ても」逆接の条件**
1. 動詞て形+ も〜
2. い形容詞（~~い~~）->〜くて＋も〜
3. な形容詞（~~な~~）->〜でも〜
4. 名詞＋でも〜
**例：**
- 安くても、旅行が嫌いです。
- 8月になっても海へ行きません。
- 日曜日でも、働きます。
- 静かでも、本が読めません。
- 雨が降っても、出かけます。

## 形容詞と名詞の繋ぎ方

***With いー形容詞　we remove い and put くて to indicate multiple adjectives***
**例：**
- 美味しくて、大きくて、赤い<ruby>林檎<rt>りんご</rt></ruby>を食べました。
- 先生は頭が良くて、優しいです。
- あさこちゃんは性格良くて綺麗です
- この車は早くて強くて便利です
***With なー形容詞 we put で to indicate multiple adjectives and same for nouns***
**例:**
- 綾音（あやね）さんがきれいで、優しいです。
- 夏先生は教師で翻訳家です
- この家は静かできれいで広いです
***we can also use this connection to state reason for something**
- この質問が難しくて、答えられません。
- カイロは人が多くて、賑やかです
- 人が多くて、<ruby>緊張<rt>きんちょう</rt></ruby>しているんです
**But we can't use this form of connection with 〜欲しいです、〜たい**
例えば：ー
- 暑いですから、ファンが欲しいです
- この本が綺麗ですから、読みたいです
***Using けど to say but it is....***
- エンジニアが便利だけど、難しいです。
- この部屋は静かだけど、広いです。
- 日本語が難しけど、楽しいです。

## 「他動詞て形＋あります」VS「自動詞て形＋います」
**ノートス：ー**
- 〜が＋自動詞「て」形＋います・いる。　**動作の結果が続いている**
- 〜が＋他動詞「て」形＋あります・有る。**誰かが何かの目的で行動した結果の状態が続いている**　
- 英語説明：we use 〜が＋自動車＋ている・ています to state something is seen in front of speaker and we use 〜が＋他動詞+て有ります・有る to state someone did an action and result of this action is still seen and happening.
**例：**
- 壁にポースタが貼って有ります。
- この文に難しいの漢字が書いて有ります。
- 部屋の中にテーブルが置いて有る。
- 果物と野菜が有っている。
- 窓が割れています。
- ドアが開いています。
- 鍵が掛けています。
- テレビが消えています。
- スパの袋が破れています。
- 傘が折れている。
