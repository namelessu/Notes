## 「動詞(たい)形 」希望と願望を示す
**ノートス：ー**

|       | 活用        |
| ----- | --------- |
| 現在形   | 動詞＋たい     |
| 過去形   | 動詞＋たかった   |
| 現在否定形 | 動詞＋たくない   |
| 過去否定形 | 動詞＋たくなかった |

**例：ー**
- 電話したかったですけど、私の電話故障でした。
- 合格したかった、でも勉強しないから、失敗した。
- 本を読みたい。
- ラメンを食べたいです。
- ミラさんに会いたくない
- 納豆は絶対食べたくない。

## 日本語の平叙文(declarative sentence)

**ノートス：ー**

|       | 丁寧形                      | 普通形       |
| ----- | ------------------------ | --------- |
| 現在形   | 名詞＋です                    | 名詞＋だ      |
| 過去形   | 名詞＋でした                   | 名詞＋だった    |
| 現在否定形 | 名詞＋じゃ有りません・では有りません       | 名詞＋じゃない   |
| 過去否定形 | 名詞＋じゃ有りませんでした・では有りませんでした | 名詞＋じゃなかった |
**例：ー**
- 私は元気じゃ有りません・じゃない。
- 雨じゃ有りません・じゃない。
- 私は大学院だ・です、木村さんも大学院だ・です。
- 来年私は学生でした・だった。
- 先月私達は元気でした・だった、今私達はとても元気じゃ有りません・じゃない。
- あのやつは僕の友達じゃ有りませんでした・じゃなかった。

## 比較の「より」(comparison)
**ノートス：ー**
- 名詞１＋の方が＋名詞２＋より＋形容詞。
- 名詞１＋は＋名詞２＋形容詞。
*質問の仕方*
- AとBどっちらが好きですか。
**例：ー**
- 太陽は蝋燭より明るい。
- バソコンは電卓より速いでしょう。
- 雪の方が雨がよりいいと思います。
- 野菜の方がポテチより体にいい。
- コーヒーの方がお茶より好きです。
## 日本語の助詞。
#### **肯定文**
**がvsは（旧情報と新情報）（old info and new info）**
###### **「対比(Contrastive)のは」話題のマーカthe topic marker **
**ノトス：ー**
- 旧情報→「は」。
- 主題の「は」＋疑問詞。
**例：ー**
- これは何ですか。
- これは中村先生の歴史本だろう。
#### **「中立叙述(Neutral descriptive)のが」　the subject/identifier marker**
**ノトス：ー**
- 新情報→「が」
- 疑問詞疑問文（どれ、どんな、いつ、何、誰）＋が
**例：ー**
- 私が警察官です。
- 潤子さんが教師ですか。
- スーパーの駐車場に車が沢山有ります。
- どれが佐藤さんの電車ですか。**（疑問文）**
- 誰が学生ですか。**（疑問文）**
- これが私のペンです
**会話例：ー**
- A：ルビちゃん誰が好き。　「冗談だ、笑！　：）」
- B：愛すクレムよりもあなた。
#### **「も」副助詞（係助詞）the inclusive topic marker**
**例：ー**
- 私は学生です花子ちゃんも学生です。
- 私は日本を勉強する、港さんも日本語を勉強する。
#### **「か」質問のマーカ the question marker.**
**ノートス**
- 〜か〜か　to say or.
- 〜か　for question marking.
- 〜か〜どうか　to ask whether or not.
**例：ー**
- 今日は暑いですか . 
- 来週の会議は木曜日か金曜日ですか。
- このことは鉛筆かプルペンですか。
- 来週僕達は動物園か映画館へ行きましょうか。
- 誕生日はお父さんかお母さんがケーキを作ってくれます。
- 今日はケーキかラメンを作ると思う。
- 明日はまみさんも来るかどうか知っている。
#### **「の」 連体助詞the possessive particle**
**例：ー**
- これはミルクちゃんの鞄です。
- 麻子は自分の彼女名前です。
- これはねんだ先生のリンゴです。
- それは本当に佐藤さんの傘です。
- あなたの奥さんの生年月日は何ですか。
- 今日の天気は悪いのでした。
- 日本の映画が面白いですね。
- スパの近くに駅があります。
- この映画の主人公はトムジェレです。
#### 「で」格助詞　the method particle
**例：ー**
- 電車で駅に行き友達に合う
- 大学に車で行きます
- 娘は桜大学で数学を習っていました。
- 私はCIC大学で通信工学を習いました。
#### 「から」格助詞 starting point particle
**ノートス**
- 起点（始まり）と終了点（終わり）を示す→（開始時間と終了時間・開始場所と終了場所）。
- 理由示す。
- 接続行動を示す。
- 原材料を示す。
- 行動の起源を示す。
**例：ー**
- 雨が降るから、サッカーの試合に行けません。**(理由を示す)**
- 宿題を終わったから、ゲムを遊ぶ。**（接続行動)**
	- 英語翻訳：Since i finished home work i will play a game
- 本店は午前９時から、午前５時まで開店しています。（開始時間と終了時間）。
- ワインは葡萄から作られます。**（原材料）**
- 授業から哲学を習ってくれた。**（行動の起源）**

###  一番「動詞たらー形 」

***「〜ても」逆接について****
1. 動詞て形+ も〜

**不定形の作り方→動詞~~ない~~ければ**
**例：ー**

- ドアが閉まれば、電気はつきません。

- 橋ができれば、島まで２０分で行けます。
- 雨が降ればサッカの試合が中止されます。
