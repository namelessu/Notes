### 歴史的に紹介「形容詞VS形容動詞」
**日本語古文の形容詞と形容動詞の違い「余り大切なこと」**
**形容詞**
物事の性質や状態を表す用言。終止形（言い切りの形）が「し」となるもの。  
**例**「よし」「美し」「多し」など。
**形容動詞**
物事の性質や状態を表す用言。終止形（言い切りの形）が「なり」「たり」となるもの。  
**例**「あはれなり」「静かなリ」「堂々たり」など。

---
**形容動詞と形容詞の活用：ー**
*普通形の活用例*

|       | イー形容詞   | なー形容詞           |
| ----- | ------- | --------------- |
| 現在形   | 難しい     | 綺麗だ             |
| 過去形   | 難しかった   | 綺麗だった           |
| 現在否定形 | 難しくない   | 綺麗じゃない・ではない     |
| 過去否定形 | 難しくなかった | 綺麗じゃなかった・ではなかった |
*丁寧形例*

|       | イー形容詞     | なー形容詞                   |
| ----- | --------- | ----------------------- |
| 現在形   | 難しいです     | 綺麗です                    |
| 過去形   | 難しかったです   | 綺麗でした                   |
| 現在否定形 | 難しくないです   | 綺麗じゃありません・ではありません       |
| 過去否定形 | 難しくなかったです | 綺麗じゃありませんでした・ではありませんでした |
>[!important] 注意
> なー形容詞の後に名詞があったら、名詞の前に「な」を加えています。

### 普通の使い方
**例：ー**
- 実用的な機械ですね。
- お手洗いは汚かったです。
- 授業はつまらなかった。
- 旅行は楽しかったね。
- 待ち時間が長くなかったです。
- 春子さんは背が長くて、頭が良くて、顔が綺麗だ。
- 時間がないので早く食べなきゃ。
**小さい会話例：ー**
- A：東京はどんな町ですか。
- B：えっと、賑やかだし、人も多いし、きれいな町です。
---
### 変化することについて表す方法
**ノートス：ー**
- 形容動詞＋になる
- 形容詞＋~~い~~くなる
**い形容詞：ー**
- 暑い　　→　暑くなります
- 寒い　　→　寒くなります
- 冷たい　→　冷たくなります
**なー形容詞**
- 大丈夫　→　大丈夫になります
- 元気　　→　元気になります
- 綺麗　　→　綺麗になります
**名詞：ー**
- 名詞＋になります。***「形容動詞と同じ活用です」***
**例：ー**
- 英語の教師になりたいです。
- 日本語が上手になりました。
- 夏になったので、暑くなった。
- 仕事が段々忙しくなっています。
- コーヒーを読む時が眠くなりません。
