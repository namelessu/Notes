## 普通形動詞と丁寧形動詞
### 紹介
日本には内と外の考え方があり、相手の立場や関係によって言葉づかいが変わる。目上・外の人には丁寧語で敬意を示し、内の人や親しい人には普通形で距離を縮める。
**例**

|       | 丁寧形      | 普通形    |
| ----- | -------- | ------ |
| 現在形   | 建てます     | 建てる    |
| 過去形   | 建てました    | 建てた    |
| 現在否定形 | 建てません    | 建てない   |
| 過去否定形 | 建てませんでした | 建てなかった |

**例：ー**
- 明日早く起きない。
- 電話番号を教える。
- 学校に行きます。
- この携帯電話が使えません。
