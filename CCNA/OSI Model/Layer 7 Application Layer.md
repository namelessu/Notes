**Definition of Application layer**
![[application-layer.png]]
The Application Layer serves as the interface between the end-user applications and the underlying network services. This layer provides protocols and services that are directly utilized by end-user applications to communicate across the network. Key functionalities of the Application Layer include resource sharing, remote file access, and network management.
**Example of application layer**

| Example                                    | Usage                                                        |
| ------------------------------------------ | ------------------------------------------------------------ |
| POP3(Post office protocol 3)               | Used by email clients                                        |
| SMTP(Simple message transfere protocol)    | Used by email clients                                        |
| FTP(File transfere protocol)               | Used to transfer data such as download and upload procedures |
| HTTP/HTTPS (Hyper text transfere protocol) | Browsing protocols                                           |
| DNS(Domain name service)                   | Resolves IP to names                                         |
| SNMP(Simple Network management protocol)   | Collecting and managing network devices across network       |
| IMAP(Internet Message Access Protocol)     | Used by email clients                                        |
| Telnet                                     | Serves as a way to access the end-devices without encryption |
| SSH(Secure Shell host)                     | Serves as a way to access the end-devices with encryption    |
