## Functionalities of Network layer
- Packetizing.
- Packet forwarding .
- Host to host deliveries.
- Fragmentation and reassembly of packets (Provides more QOS control)
- Logical addressing and subnetting(Network Dividing).
- Network Address Translation(NAT): Transferring the private IP to public IP.
